# QuoteCheck demonstration

Target: a short recording of the real local app, in English, showing real model calls. Only the QuoteCheck tab is in scope. No account pages, unrelated tabs, camera, microphone, credentials or actual supplier/customer information.

1. Show the initial brief: 1,000 boxes, $2,800 maximum, delivery by November 28, at least 70% recycled content.
2. Compare $2,615 for Alder and $2,650 for Paperfield. Northline's $2.05 unit price is lower, but its complete total is unknown because freight is not quoted.
3. Open Northline's freight citation. Show line 6 in the original source. Close it.
4. Run a real review. Show source inspection and review completion. Open a citation in the result. The clarification question remains unsent.
5. Apply “Need it by Nov 23”. Show Alder outside the brief and Paperfield as the only complete match. The earlier review is no longer current.
6. Run a fresh real review. Show the recommendation responding to the changed requirement.
7. Open review history. Show revisions and the shared action log with human and assistant callers.
8. Export the planning memo. It separates calculated facts from draft wording and includes the source lines.

Useful narration/captions:

“The cheapest unit price is not always the cheapest complete offer. QuoteCheck compares source-backed costs against a purchasing brief, keeps missing charges unknown, and drafts the question that could change the decision. The human interface and the local agent use the same validated Agent-Native actions. Changing a requirement invalidates the older review. No order is approved and no message is sent.”
